# JGlow Customs — Website Case Study

## Project overview

This case study documents the public JGlow Customs website as a production snapshot. JGlow Customs is an automotive customization business serving Fairfield, California and nearby customers. The site is designed to help prospective customers understand available services, view visual examples, ask common questions, and request a quote.

The portfolio entry is intentionally presentation-only. It contains flattened screenshots and this evidence-bounded narrative; it is not a copy of the JGlow application and cannot run as the JGlow website.

Public site: [jglowcustom.com](https://www.jglowcustom.com)

## Audience and website purpose

The intended audience is vehicle owners in the Fairfield area who are exploring custom lighting, interior, wheel, and exterior styling work. The public experience organizes the offer into service overviews and detail pages, supports English and Spanish browsing, and provides several ways to start an inquiry without submitting the form during capture.

## Visible website deliverables

The screenshots show these public deliverables:

- Home, service overview, and six service-detail experiences for starlight headliners, ambient lighting, underglow, brake caliper paint, interior customization, and tire decals.
- Gallery, service-area, About, FAQ, and Contact pages.
- An English/Spanish page experience across the core marketing routes.
- A gallery with media/service filters and an open-image preview state.
- A public blog index and published English and Spanish article routes.
- Direct inquiry paths and a Contact page captured with the form empty.

Pricing, testimonials, business results, conversion metrics, and customer outcomes are intentionally not presented as claims in this case study.
